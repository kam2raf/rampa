# No-Fly Zone Viewer

A lightweight web application for viewing local no-fly zones stored in GeoJSON.

The application displays polygons on an interactive Leaflet map without requiring external GIS services.

## Features

- Leaflet map
- GeoJSON support
- Popup information
- Local dataset
- REST API

## Run

```bash
pip install -r requirements.txt
python src/app.py
```

Open

```
http://127.0.0.1:5000
```
